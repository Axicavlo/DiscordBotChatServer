# 숫자야구

디스코드 채널에서 참가자가 같은 네 자리 정답을 각자 추리하는 미니게임이다.

## 모집과 시작

- `/숫자야구`로 방을 만든다. `중복가능:y`는 같은 숫자를 여러 번 사용할 수 있고, `중복가능:n` 또는 옵션 생략은 중복 금지다.
- 채널마다 활성 방 하나를 둔다. 방장은 자동 참가하며, 나머지 사용자는 모집 임베드의 참가 버튼을 사용한다. 최대 25명이다.
- 방장이 시작하거나 방 생성 후 60초가 지나면 시작한다. 시작 후 모집은 마감된다.

## 추리와 종료

- 정답은 0~9로 이루어진 네 자리다. 0과 선행 0을 허용한다. 중복 금지 모드에서는 정답과 추측 모두 같은 숫자를 두 번 쓸 수 없다.
- 자리와 숫자가 일치하면 스트라이크다. 위치가 다른 일치 숫자는 볼이며, 스트라이크를 먼저 제외하고 남은 숫자 빈도만큼만 센다.
- 참가자마다 최대 9회 추측한다. 네 자리 모두 맞히면 성공 턴을 표시한다. 9회 실패 또는 대국 시작 후 10분이 지나면 미완료자는 실패다.
- 개인 응답에 `TURN / GUESS / RESULT` 형식으로 추측과 `nS nB`를 표시한다. 잘못된 입력이나 이미 처리된 턴은 새 시도로 반영하지 않는다.
- 공개 임베드는 참가자 명단과 성공 턴·실패를 보여준다. 전원이 결과를 냈거나 방장이 종료하거나 시간이 만료되면 방을 닫고, 생성된 정답을 공개한다.
- 진행 상태를 메모리에 유지한다.
