# 웹 오목

디스코드에서 방을 만들고 PC 또는 모바일 브라우저에서 렌주 규칙으로 1대1 대국한다. 방 하나에서 한 판을 진행한다.

## 방과 입장

- 디스코드 서버 채널에서 `/오목 방만들기`를 실행하면 공개 임베드에 참가·관전·방 닫기 버튼을 표시한다. 방장은 첫 참가 자리를 자동으로 차지하고 본인만 볼 수 있는 웹 입장 버튼을 받는다.
- 참가자는 최대 두 명, 관전자는 최대 열 명이다. 임베드에 참가자 이름과 `관전 n명`을 표시한다. 대국 중에도 관전자는 입·퇴장할 수 있다.
- 참가·관전을 누르면 봇이 클릭한 계정과 방을 생성한 서버 ID를 확인한다. 버튼을 누른 사람에게만 30초간 유효한 일회용 입장권을 제공한다. 웹은 입장권 사용 시 방 상태와 정원을 다시 확인하고 방 세션을 생성한다. 별도 웹 로그인은 없다.
- 방장 외 새 참가자의 자리는 웹 입장 확정 시 배정한다. 만석이어도 참가 버튼은 활성화해 두며 기존 참가자 ID가 일치하면 새 입장권으로 기존 자리에 복귀한다. 같은 브라우저의 유효한 방 세션으로는 바로 복귀할 수 있다.
- 한 계정은 동시에 한 방의 대국자로만 등록할 수 있고 다른 방을 관전할 수 있다.

## 대기실과 시간제

- 방장은 모드와 제한시간을 선택한다. 설정 변경 시 두 대국자의 준비를 해제한다.
- 대국자는 흑돌·백돌 버튼으로 희망 색을 선택하고 준비 상태를 전환한다. 두 명 모두 준비하면 시작한다. 서로 다른 색을 골랐으면 선택대로, 같은 색을 골랐으면 무작위로 배정한다.
- 대국 전 방장은 디스코드나 웹의 `방 닫기`로 방을 닫을 수 있다. 방장이 대기실에서 나가도 방을 닫는다. 일반 참가자가 나가면 자리를 반환한다. 방 생성 후 5분 안에 대국이 시작되지 않으면 자동으로 닫는다.

| 모드 | 방장 선택 | 기본값 | 대국 중 표시 |
|---|---|---|---|
| 일반 | 턴당 15·30·45·60초 | 30초 | 중앙 턴 문구 옆 `00:00` |
| 블리츠 | 대국자당 총 1·2·3·4·5분 | 3분 | 각 대국자 이름 오른쪽 `00:00.00` |

일반은 매 턴 시간을 새로 부여한다. 블리츠는 각자 자기 차례에만 잔여 시간을 쓰고, 유효 착수 시 상대 시계로 전환한다. 착수당 추가 시간은 없다. 서버 단조 시계 기준으로 마감 전에 도착한 유효 착수만 인정하며, 마감과 같거나 늦으면 시간패다. 화면 표시는 일반은 1초, 블리츠는 0.01초 단위로 올림한다. 시간패에 무승부 예외를 적용하지 않는다.

## 착수와 판정

- 15×15 교차점, 흑 선공, 오프닝 배치 규칙 없음. 흑은 정확히 5목, 백은 5목 이상이면 승리한다.
- [RIF 국제 렌주 규칙](https://www.renju.net/rifrules/) 9.1~9.3을 기준으로 흑의 장목·4-4·금지 3-3을 금수로 판정하며 가짜 3을 구분한다. 같은 착수에서 정확히 5목이 완성되면 5목을 우선한다.
- 유효한 빈 교차점을 처음 누르면 본인에게만 예비 마커가 보인다. 다른 유효한 자리를 누르면 마커가 이동하고, 같은 자리를 다시 누르면 서버에 착수를 요청한다.
- 금수는 예비 마커부터 차단하고 본인에게만 판 아래의 `금수입니다` 문구로 알린다. 거부된 수는 턴을 넘기거나 시간을 초기화하지 않는다.
- 서버가 승인한 마지막 돌 중앙에 빨간 점 하나를 표시한다. 다음 착수가 승인되면 점을 옮긴다. 대국자와 관전자가 같은 위치를 보고 새로고침·재입장 후에도 복원된다.
- 승자가 없고 현재 차례에 합법적으로 둘 자리가 없으면 무승부다.

## 종료와 재입장

- 대국 중 명시적으로 나가면 즉시 기권패다. 새로고침이나 네트워크 단절 중에도 타이머는 흐르며 시간패 전에 복귀할 수 있다.
- 대국이 끝나면 결과와 사유, 나가기 버튼을 웹 중앙에 표시하고 임베드에도 결과를 반영한다. 신규 참가·관전은 마감한다.
- 기존 참가자와 관전자는 종료 후 최대 1분간 결과와 채팅을 이용할 수 있다. 두 대국자가 모두 명시적으로 퇴장하면 먼저 방을 닫는다. 관전자가 남아 있어도 동일하다.
- 서버 재시작으로 진행 중인 방이 종료된 경우 미확정 대국은 기록하지 않는다. 운영 자동 배포는 열린 오목 방이 있으면 재시작을 보류한다.

## 화면과 채팅

- PC는 왼쪽 접속자, 중앙 대기실 또는 오목판, 오른쪽 채팅의 3열 구조다. 얇은 세로선 두 개로 구역을 나눈다. 채팅 제목 오른쪽에 달 아이콘과 다크 모드 토글을 둔다. 밝은 배경 기준색은 `#F2F3F5`다.
- 대기실 중앙에는 두 대국자의 `VS`, 방장 설정 및 준비 제어를 표시한다. 대국 중에는 현재 턴의 이름에 녹색 테두리를 표시한다. PC에서는 대국자 아래에 별도 관전자 목록을 표시한다.
- 모바일은 세로 배치를 사용한다. 턴·일반 타이머와 오른쪽 눈 아이콘·관전자 수를 상단에 고정한다. 오목판과 대국자 두 명을 채팅 위에 두며 관전자 명단이나 전환 탭은 표시하지 않는다. 바깥 스크롤은 화면 높이의 최대 40%이고, 스크롤하는 동안 입력창은 하단에 고정되며 채팅 영역은 위로 넓어진다. 판 아래의 점 세 개는 구역 경계 표시이며, 바깥 스크롤 이후 메시지 목록 내부를 스크롤할 수 있다.
- 채팅 메시지는 프로필 사진 왼쪽, 닉네임과 본문 오른쪽의 블록으로 표시한다. 방을 만든 Discord 서버의 정적·움직이는 커스텀 이모지와 기본 유니코드 이모지를 지원한다. 서버는 Discord 역할과 이모지 사용 가능 상태를 확인한다.
- PC 입력창은 맑은 고딕 11pt, 하단 밑줄, 기본 한 줄이다. 줄이 늘면 최대 네 줄까지 높아지고 전송 후 한 줄로 돌아온다. Enter로 전송하며 한글 조합 중에도 최종 글자를 포함해 한 번만 보낸다. Shift+Enter는 줄바꿈이다. 모바일에는 전송 버튼이 있다.

## 결과 저장

- `gomoku.record` 컬럼은 `room_id`, `player_1`, `player_2`, `win`, `is_draw`, `game_mode`다. 방 ID가 대국 결과의 기본 키다.
- 참가자·승자는 디스코드 사용자 ID로 저장한다. 무승부는 `is_draw=true`, `win=NULL`이다. 일반은 `1`, 블리츠는 `2`이며 `gomoku.game_mode.id`를 참조한다.
- 닉네임 아래에 현재 방 모드 기준 `n전 n승 n무 n패`를 표시한다. 기록이 없으면 `0전 0승 0무 0패`다. 해당 사용자가 두 참가자 컬럼 중 하나에 있는 대국을 세고, 승자 ID와 무승부 여부로 결과를 집계한다. 패수는 전체에서 승수와 무승부 수를 뺀 값이다.
- 대국 시작 전 방을 닫으면 결과를 저장하지 않는다.
